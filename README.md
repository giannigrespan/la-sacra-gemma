# La Sacra Gemma

Diario di allenamento personale.

Dashboard pubblica per tracciare gli allenamenti in palestra: volume, intensità, progressi.

## Come funziona

Un bot Grok chiede ogni giorno i dettagli dell'allenamento, aggiorna i dati e il mattino successivo fornisce un'analisi.

I dati sono in `data/workouts.json`.

## Deploy

Automatico su Vercel da questo repository.
